# Co-work Platform

Repository voor het NKC website MVP.

## Huidige afspraak

De eerste implementatie moet een zo nauwkeurig mogelijke 1-op-1 vertaling worden van de Figma-schermen voor de ingelogde gebruiker.

Niet bouwen op basis van een globale indruk van het canvas. Gebruik eerst exacte frames, screenshots/exports en assets.

## Designbron

- Lokale export: `C:\Users\Dave Hoekstra\Downloads\NKC - website (MVP).fig`
- Focus: alleen de ingelogde gebruiker-schermen

De `.fig` export bevat het volledige Figma-bestand. Dat is handig als bron voor toekomstige pagina's, maar de interne `canvas.fig` is een Figma-specifiek binary formaat. Voor exacte implementatie gebruiken we daarom Figma-import/inspect, MCP/plugin-toegang, of losse frame-exports als PNG/SVG/assets.
